# AutoCaller

Google スプレッドシートの電話番号リストに順番に発信する macOS アプリです。
相手が出たら通知音が鳴り、**Space キー**で次の番号へ進みます。

> このリポジトリは**配布専用**です (ビルド済みアプリのみ)。

---

## 📥 インストール (最初の 1 回だけ)

### 1. ダウンロード

**[⬇ 最新版をダウンロード](https://github.com/takazawasorato/auto-caller-releases/releases/latest)** を開き、
`AutoCaller-x.y.z.dmg` をクリックしてダウンロードします。

### 2. アプリケーションフォルダへ

1. ダウンロードフォルダの **`.dmg` をダブルクリック**して開きます
2. 開いた窓で **AutoCaller のアイコンを、右の「Applications」フォルダへドラッグ**します
3. ドラッグが終わったら窓を閉じ、`.dmg`(デスクトップ or Finder サイドバー)を取り出します
4. **アプリケーションフォルダの AutoCaller をダブルクリック**して起動

### 3. ⚠️ 「開けません」と出たら (初回だけ)

Apple 署名のないアプリのため、初回だけ警告が出ます。次の手順で開けます:

1. 警告ダイアログの **「OK」** を押して閉じる
2. **アップルメニュー  → システム設定 → プライバシーとセキュリティ** を開く
3. 下の方にスクロールすると
   **「"AutoCaller" は…開けませんでした」** という行があります
4. その隣の **「このまま開く」** ボタンをクリック
5. Mac のパスワードを入力 → **「開く」**

> 💡 **2 回目以降は普通にダブルクリックで開けます。** この手順は初回だけです。
> (「OK」しか出ないダイアログでも、システム設定に必ず「このまま開く」があります)

## 🔧 最初の設定

アプリを開くと**セットアップウィザード**が案内してくれます:

1. **creds.json の取り込み** — 管理者から受け取ったファイルを選択
   (スプレッドシート連携の鍵。取り込むと表示されるメールアドレスを、
   使いたいシートに「編集者」で共有してください)
2. **電話アカウント** — ここは基本 **スキップで OK** です。
   案件を選ぶと管理シートの情報から電話アカウントが**自動で登録・切り替え**されます。
   (どうしても手動で入れたい場合だけ 端末ログインID / ドメイン / パスワード を入力)
3. **マイクの許可** — 「許可」を押す
4. **テスト発信** — 任意

> 📄 **管理シート URL** は、初回に一度だけ **設定 → 基本** で入力します
> (管理者が用意した「電話番号管理シート」の URL)。以降は案件を選ぶだけで
> 発信先・電話アカウント・記入先が自動で設定されます。

必要な情報 (creds.json・管理シート URL) は**管理者から安全な方法で受け取ってください**。

> 💡 **Mac mini など内蔵マイクが無い機種**では、先にマイク付きヘッドセット
> (USB か 3.5mm) を接続してください。無いと通話が接続直後に切れます。

## ☎️ 毎日の使い方

1. **AutoCaller をダブルクリック** (電話系も自動で立ち上がります)
2. 画面の案内に沿って **案件 → 自分の名前 → どこから始めるか** を選ぶ
3. **「確認へ →」** を押すと発信画面に移り、1 件目の相手と発信アカウントが表示されます
   (このとき、その案件の電話アカウントに自動で切り替わります)
4. 内容を確認して **「▶ 開始」** を押すと発信が始まります
5. **相手が出ると自動で一時停止**し、通知音が鳴って通話に入ります
6. 話し終えたら **Space キー**(または **「▶ 切電して次へ」**)で切電 → 次の番号へ
   - 相手が出なかった場合も一時停止するので、**Space** で次へ進みます
   - 商談が決まったら、一時停止中に **「商談設定」** でシートに記入できます
7. やめるときは **「■ 終了」**

> 💡 **録音** は発信画面右上のボタンで ON / OFF を切り替えられます
> (🔴 録音ON のとき、通話中は「🔴 録音中」と点滅表示)。

---

## ⬆️ アップデート

新しいバージョンが出ると、起動時に **「今すぐ更新しますか?」** と表示されます。
**「はい」を押すだけ**で、ダウンロード → 差し替え → 再起動まで自動です。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「開発元を確認できないため開けません」 | 上記「3. 開けませんと出たら」の手順 (初回だけ) |
| ログに `401 Unauthorized` | 端末ログインID かパスワードの入力ミス。アカウント設定で入れ直して「baresip 再起動」 |
| 「baresip ctrl_tcp に接続できません」 | 「baresip 再起動」ボタン。直らなければアプリを再起動 |
| 相手が出た直後に切れる | マイクが無い状態。ヘッドセットを接続 |
| シートが読めない | creds.json 未取込、またはシートが未共有 → 管理者へ |

解決しないときは、アプリのログ欄のスクリーンショットを管理者に送ってください。
